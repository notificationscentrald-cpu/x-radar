# X Radar у стрічці (розширення Chrome)

Гортаєш стрічку X, а під кожним постом з'являється бейдж з X-фактором:
**перегляди / підписники автора** (знаменник не менше 100), та сама формула, що в `radar.py`.

- 🔴 **⚡ ×80** червоний: радар би це спіймав (X-фактор ≥ 15, ≥ 50K переглядів, автор до 50K підписників).
- 🟠 помаранчевий: X-фактор ≥ 5, пост помітно перебиває аудиторію автора.
- ⚪ сірий: звичайний пост. Блідий: великий акаунт (понад 50K), радар такі пропускає.
- **×?**: X ще не віддав кількість підписників автора (буває рідко).

## 💬 Де реплаїти
Поруч з'являється другий бейдж на свіжих постах (до 60 хв, до 50 реплаїв, не реплай у треді):
**💬 реплай · 12 хв · 8 репл. · ~40K попереду**.
- «Попереду» = скільки переглядів пост іще збере (оцінка: половина переглядів за ~45 хв, за даними дослідження 5 000 твітів).
- Бал = «попереду» ÷ (1 + реплаї / 20), ×1.5 якщо пост про твою нішу (Claude, 3D, ігри, AI…).
- **Зелений** = топ-3 серед постів, які ти бачив за останні 30 хв. Під ними й реплаїмо (2–5 на день).
- Сірий «можна» = свіжий, але не в топі.

**Журнал реплаїв.** Кнопка 💬 зліва внизу. Розширення саме запам'ятовує кожен твій реплай (під яким постом,
вік, реплаї, прогноз) і підтягує його покази, коли X їх показує. Через добу відкрий свій профіль → Replies.
Після 15–20 реплаїв натисни «Скопіювати CSV» і кинь Claude: підженемо пороги під твої реальні цифри.
Журнал лежить лише в цьому браузері.

Ключі API не потрібні: розширення читає дані з тих самих відповідей, які X і так завантажує в браузер.
Нікуди нічого не відправляє.

## Встановлення (2 хвилини)
1. Завантаж репозиторій: зелена кнопка **Code → Download ZIP** і розпакуй (або `git clone`).
2. Відкрий у Chrome `chrome://extensions`.
3. Справа вгорі увімкни **Режим розробника** (Developer mode).
4. Натисни **Завантажити розпаковане** (Load unpacked) і вибери папку `extension`.
5. Онови вкладку з x.com. Бейджі з'являться під постами, над рядком лайків.

Після оновлення файлів натисни ↻ на картці розширення в `chrome://extensions` і онови x.com.

Пороги міняються вгорі файлу `xfactor.js` (`MIN_X_FACTOR`, `MIN_VIEWS`, `MAX_FOLLOWERS`, `REPLY_*`, `NICHE_RE`).
