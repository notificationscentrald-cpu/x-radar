# X Radar (свій)

Щогодини шукає в X пости твоєї ніші, що летять **на малих акаунтах**, і шле їх у Telegram.
Щоранку о 9:00 за Києвом шле топ-20 за добу. Ідея та сама, що в X-радара Superior:
мало підписників + багато переглядів = летить тема, а не автор, отже її можна повторити.

## Як рахує
- **X-фактор** = перегляди / підписники автора. Поріг у `config.json` (`min_x_factor`, за замовчуванням ×20).
- Відсіює великі акаунти (`max_followers`), слабкі пости (`min_views`), реплаї й репости.
- Сортує за X-фактором і швидкістю (переглядів за годину). Не шле один пост двічі.
- Якщо додати ключ Anthropic, Claude дописує під кожен пост: чому летить і два свої кути.

## Що налаштувати
`config.json`: запити в синтаксисі пошуку X (`min_faves:`, `filter:videos`, `OR`, `lang:` працюють), пороги, кількість сповіщень.

## Запуск
**Варіант А, GitHub Actions (безкоштовно, працює без твого компа):**
1. Створи приватний репозиторій на GitHub і завантаж туди вміст цієї папки (разом з `.github`).
2. Settings → Secrets and variables → Actions → додай `TWITTERAPI_IO_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, за бажанням `ANTHROPIC_API_KEY`.
3. Actions → x-radar → Run workflow, щоб перевірити одразу.

**Варіант Б, на компі:** скопіюй `.env.example` у `.env`, заповни, потім
`python3 radar.py --dry` (перевірка без Telegram), `python3 radar.py --loop 60` (працює, поки відкритий термінал).

## Ключі
- **twitterapi.io**: зареєструйся, поповни на $5–10, скопіюй API key у кабінеті.
- **Telegram**: напиши @BotFather → /newbot → отримаєш токен. Напиши своєму боту будь-що, відкрий
  `https://api.telegram.org/bot<ТОКЕН>/getUpdates` і візьми `chat.id`. Для каналу: додай бота адміном, id каналу починається з -100.

## Скільки коштує
Один запит ≈ 20 постів ≈ $0.003. 4 запити щогодини ≈ $0.30 на день, близько $9 на місяць.
Розбір Claude Haiku додає копійки (до 5 постів за прохід).
