# AirMouse — керуй курсором Mac рухом AirPods

Читає гіроскоп/акселерометр AirPods через CoreMotion (`CMHeadphoneMotionManager`) і рухає курсор.
Тап по кейсу (різкий поштовх) = клік. Працює з AirPods Pro (1/2/3), AirPods 3/4, AirPods Max на macOS 14+.

## Збірка (один раз, ~1 хв)
```bash
xcode-select --install        # якщо ще немає інструментів командного рядка
cd tools/airmouse
./build.sh
```

## Запуск
```bash
./AirMouse.app/Contents/MacOS/AirMouse
```
Запускай із Терміналу, щоб бачити логи. У рядку меню з'явиться 🎧.

Перший запуск попросить два дозволи:
1. **Motion & Fitness** (рух) — дозволь.
2. **Accessibility** (Універсальний доступ) — System Settings → Privacy & Security → Accessibility → увімкни AirMouse. Без цього курсор рухається, а кліки не працюють.

## 5-хвилинна перевірка «чи віддає дані в кейсі»
1. Підключи AirPods до Mac (вставити у вуха, дочекатись з'єднання, звук має йти через них).
2. Запусти AirMouse. Лог має показати `Headphone motion available: true` і раз на 5 с рядок `samples=...`, число росте.
3. Поклади навушники у відкритий кейс. Якщо `samples` далі росте і курсор рухається, коли нахиляєш кейс — всьо, можна знімати.
4. Якщо після кладення в кейс рядки зупинились або прийшов `AirPods disconnected` — macOS відключає навушники в кейсі. Тоді варіанти: тримати кейс відкритим і трохи висунути навушник (сенсор вуха має бачити «світло»), або заклеїти датчики наближення шматочком малярного скотчу. У Andy Gao працює саме відкритий кейс.

## Налаштування (меню 🎧)
- ⌥⌘A — старт/стоп, ⌥⌘= / ⌥⌘- — чутливість
- Invert / Swap axes — якщо курсор іде не туди (залежить від того, як тримаєш кейс)
- Tap case to click — вимкни, якщо кліки спрацьовують випадково

## Обмеження
- У самому кейсі датчиків немає; працюють датчики навушників усередині.
- Є дрейф і тремтіння: мертва зона 0.03 рад/с і згладжування вже є, підкрути в `main.swift` за потреби.
- Клік визначається по сплеску прискорення > 1.4 g; під час різкого руху можливий хибний клік.
