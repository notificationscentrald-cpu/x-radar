# Голем-тамагочі: віджет для iPhone

Гранітний голем живе у віджеті на головному екрані: гуляє, стукає в скло, протирає його, їсть, радіє, сумує і спить уночі. Три кнопки працюють прямо у віджеті: 🪨 нагодувати, 🤚 погладити, ✊ постукати.

Працює в безкоштовному застосунку **Scripting** (App Store, iOS 17+). Mac не потрібен.

## Встановлення
1. Постав Scripting з App Store.
2. У Scripting створи новий скрипт з назвою `Golem`.
3. Відкрий у ньому `index.tsx`, видали все і встав вміст файлу [`index.tsx`](index.tsx) звідси.
4. Натисни ▶ (Run). Він сам завантажить `golem-widget.zip` (код віджета і 176 кадрів).
5. Головний екран: затисни порожнє місце → Редагувати → Додати віджет → Scripting → середній розмір. Потім затисни віджет → «Редагувати віджет» → Script: `Golem`.

## Файли
- `widget.tsx`: сам віджет (покадрова анімація + кнопки)
- `app_intents.tsx`: що роблять кнопки
- `golem_state.tsx`: їжа, настрій, яку сцену показати
- `golem-widget.zip`: усе разом плюс кадри `frames/<сцена>/NN.jpg` (480×224)
- `render/`: як кадри відрендерено з 3D-моделі голема (three.js + Playwright)
